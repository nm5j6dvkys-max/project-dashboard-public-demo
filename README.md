# 项目协作台 · 在线体验版

轻量化项目任务管理与进度跟踪系统。纯静态网站，无需安装、登录或后端数据库。

## 在线使用

https://nm5j6dvkys-max.github.io/project-dashboard-public-demo/

首次访问没有项目、任务或风险记录，不初始化任何示例数据。创建项目 → 新增任务 → 设置负责人和日期 → 更新状态 → 查看进度及汇报。

## 功能

- 项目创建、编辑、删除和详情；新增项目阶段。
- 任务增删改查、负责人或角色、优先级、起止日期、状态、前置依赖、进度和历史记录。
- 搜索筛选、任务列表、可拖拽看板和甘特图。
- 创建关联任务的里程碑，按已完成任务数量计算项目完成率；没有任务时显示 —。
- 临近截止、逾期、延期和阻塞识别；主动记录任务风险并更新处理状态。
- 按项目及月份统计、状态分布、周报和阶段汇报、JSON/CSV 导入导出。
- 经确认清空当前浏览器的体验数据，恢复空白状态。

## 数据与隐私

- 唯一持久存储键：`projectDashboardPublicDemo:v1:workspace`。
- 只读取这个公开体验版键，不枚举、读取或迁移其他应用的存储。
- 项目、任务、风险与历史只保存在访问者当前浏览器的 localStorage；刷新保留，不跨浏览器、设备同步。
- 不上传任务内容，不配置服务端 API、分析追踪器、外部字体或第三方脚本。CSP 的 `connect-src 'none'` 禁止应用网络连接。
- GitHub Pages 仍会接收网页和静态资源请求；浏览器本地存储不代表网页托管服务没有访问日志。
- 同域名下独立存储键属于应用层命名空间隔离，并不是来源级隔离。如需严格隔离，应使用不同域名。共用同一浏览器用户配置的人会看到该浏览器的数据。
- 清空操作只写入本应用的空数据结构，不调用 localStorage.clear()，不影响其他应用。
- 公开源代码不包含预置项目、任务、业务资料、个人数据、报告、截图或历史仓库提交。

## 统计口径

完成率 = 已完成任务数量 / 截至统计日已创建的任务数量。任务数量为零时显示 —。任务进度由使用者输入，不直接作为项目完成率。默认统计日期为当天（Asia/Shanghai），可选择日期回放任务历史。周报汇总截至统计日的最近七天记录。

里程碑在全部关联任务完成后交付。任务删除保留历史，关联里程碑不会因删除而自动完成。删除项目会移除该项目及其关联数据，建议先导出 JSON。关闭风险记录不会自动完成任务，自动截止风险仍由任务状态和日期判断。

## 本地预览与部署

使用任意静态 HTTP 服务器打开仓库根目录，例如 `python3 -m http.server 8080`。

GitHub Pages 设置：Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save。全部资源使用相对路径，兼容仓库子路径。无需依赖安装或构建步骤。`.nojekyll` 禁用 Jekyll 处理。

本仓库从清理后的应用文件建立，独立于其他版本，不携带其他仓库的提交历史。
